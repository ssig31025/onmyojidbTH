# Game Modes

Guides for various game modes in Onmyoji.

## PvE Modes
- **Secret Zones**: Challenge stages with unique mechanics.
- **Assembly Bosses**: World bosses that spawn daily.
- **Exploration**: Farming experience and materials.

## PvP Modes
- **Duel**: Real-time player vs player combat.
- **Royal Battle**: Draft mode PvP.
